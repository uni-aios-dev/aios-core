ХАРАКТЕРИСТИКИ TEE
================================================================================

Platform Detection:
   ✅ Windows (x86-64): SGX + SEV
   ✅ Linux: SGX + SEV + TrustZone
   ✅ ARM64: TrustZone via /dev/tee

Sealing Key Features:
   - SHA-256 derivation
   - Platform binding (fail if platform changes)
   - Full serialization support

Attestation Features:
   - MRENCLAVE (enclave measurement)
   - MRSIGNER (signer measurement)
   - PCR values (Platform Configuration Registers)
   - Verification status tracking

Enclave Lifecycle:
   Created → Initialized → Running ↔ Suspended → Exited/Failed
   - Custom data storage
   - Thread management (add/remove with limits)
   - State preservation
