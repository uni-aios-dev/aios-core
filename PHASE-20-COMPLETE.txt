FEATURES IMPLEMENTED
================================================================================

A. TEE PLATFORM DETECTION
   - Intel SGX (x86-64) detection via CPUID leaf 7, bit 2
   - ARM TrustZone (aarch64) detection via /dev/tee device files
   - AMD SEV (x86-64) detection via CPUID leaf 0x8000_0001, bit 2
   - Graceful fallback for unsupported platforms
   - Hardware capability reporting (max sealed size, attestation capability)

B. DATA SEALING (sealing.rs)
   - SealingKey: Cryptographic keys with platform binding
   - SealedData: Encrypted buffers with integrity tags
   - Key derivation: SHA-256 based from secret + platform identifier
   - Platform-locked unsealing (fails on platform changes)
   - Full serialization via bincode for IPC transport

C. ATTESTATION FRAMEWORK (attestation.rs)
   - AttestationReport: Enclave measurements (MRENCLAVE, MRSIGNER)
   - Attestation: Report with verification status and PCR values
   - Remote verification support (timestamp, signature validation)
   - PCR (Platform Configuration Register) management
   - Report hashing for integrity verification

D. ENCLAVE LIFECYCLE MANAGEMENT (enclave.rs)
   - EnclaveState: Created → Initialized → Running → Suspended → Exited/Failed
   - EnclaveConfig: Memory size, thread count, debug mode configuration
   - Enclave: Full lifecycle with state preservation
   - Thread management: Add/remove threads with limit enforcement
   - Custom data storage for application-specific enclave data
   - State serialization for persistence and recovery

E. CROSS-PLATFORM SUPPORT
   - Windows x86-64: Full SGX and SEV detection
   - Linux: SGX, SEV, and TrustZone support
   - ARM64: TrustZone detection via /dev/tee
   - Conditional compilation for platform-specific code

ARCHITECTURE NOTES

   3. aios-core: Uses aios_core::error::Result for error handling

Data Flow:
   Sealing:   Secret → SHA-256 + Platform ID → Encrypt → SealedData
   Attestation: Enclave → Measure → Report → Attest → Verify
   Enclaves:  Create → Init (with measurement) → Run → Suspend/Resume → Exit

Cross-Platform Considerations:
   - CPUID access: Safe function, no unsafe required
   - Device files: /dev/tee* checked for existence
   - Conditional compilation: Platform-specific code isolated
   - Fallback: Non-TEE systems work in degraded mode
