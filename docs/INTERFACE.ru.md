# Интерфейс AIOS — Руководство пользователя

## Обзор

AIOS предоставляет два интерфейса для управления системой:

| Интерфейс | Тип | Бинарник | Назначение |
|-----------|-----|----------|------------|
| **Web** | Браузерный SPA (HTML/CSS/JS) | `aios-studio/` на `http://<host>:<port>/` | Удалённое управление, визуальный дашборд, любое устройство |
| **TUI** | Терминальный (ratatui) | `aios-tui` | SSH, интерактивный, клавиатура |
| **GUI** | Нативное окно (egui/eframe) | `aios-gui` | Desktop, визуальный дашборд, мышь + клавиатура |
| **Daemon** | Фоновый сервер | `aiosd` | Docker, фон, CI/CD, без терминала |

Оба интерфейса отображают одни и те же данные и предоставляют одни и те же операции. GUI — это графический аналог TUI.

## TUI (`aios-tui`)

### Запуск

```bash
cargo run --bin aios-tui
```

### Компоновка

```
┌──────────────────────────────────────────────────────┐
│ AIOS v1.0.0 | Tier1 | WD: OK | CPU: 16 | RAM: ...  │  ← Заголовок
├──────────────────────────────────────────────────────┤
│ Overview │ Processes │ Blocks │ Metrics │ Deps │ Web │ Shell │  ← Вкладки
├──────────────────────────────────────────────────────┤
│                                                      │
│              Основная область содержимого             │
│                                                      │
├──────────────────────────────────────────────────────┤
│ q=Выход Alt+1-7=Вкладки j/k=Навиг. K=Убить U=Выгр L=Заг H=Зам F1=Справ :=Ком│  ← Подвал
└──────────────────────────────────────────────────────┘
```

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `1`-`7` | Переключить вкладку (Обзор / Процессы / Блоки / Метрики / Зависимости / Web / Shell) |
| `Alt`+`1`-`7` | Переключить вкладку даже при активной командной строке Shell или строке URL Web |
| `j` / `k` | Навигация вниз / вверх в текущем списке |
| `K` | Убить выбранный процесс |
| `U` | Выгрузить выбранный блок |
| `L` | Загрузить блок с диска (запрашивает имя + версию) |
| `H` | Горячая замена бинарника блока |
| `r` | Обновить данные |
| `s` | Показать телеметрию |
| `x` | Показать статус |
| `q` | Выход |
| `F1` или `?` | Открыть/закрыть справку |
| `:` | Войти в режим команд на вкладке Shell |
| `Enter` | Выполнить команду на вкладке Shell |
| `↑` / `↓` | История команд на вкладке Shell |

### Вкладки

- **Обзор**: Информация о системе (CPU, GPU, хранилище) + журнал активности
- **Процессы**: Таблица с PID, Имя, Приоритет, Состояние, RAM, CPU, Сбои + панель деталей
- **Блоки**: Таблица с ID, Имя, Версия, Состояние, Размер + операции загрузки/выгрузки/замены
- **Метрики**: Шкала RAM, распределение приоритетов, график истории RAM
- **Зависимости**: Граф зависимостей + цепочка загрузки
- **Web**: Строка URL, текст страницы, список ссылок
- **Shell**: Интерактивная командная строка с историей, fetch, search, open, clear

### Клавиши вкладки Web (когда активна вкладка Web)

| Клавиша | Действие |
|---------|----------|
| `g` | Фокус на строку URL |
| `Enter` | Перейти по URL (когда строка URL в фокусе) |
| `o` | Открыть выбранную ссылку |
| `j` / `k` | Переместить выбор ссылки вниз/вверх |
| `Esc` | Снять фокус со строки URL |

### Клавиши вкладки Shell (когда активна вкладка Shell)

| Клавиша | Действие |
|---------|----------|
| `:` | Войти в режим команд |
| `Enter` | Выполнить команду |
| `↑` / `↓` | Навигация по истории команд |
| `Esc` | Выйти из режима команд |

### Команды Shell

| Команда | Аргументы | Описание |
|---------|-----------|----------|
| `fetch` | `<url>` | Загрузить блок по URL |
| `search` | `<query>` | Веб-поиск через DuckDuckGo |
| `open` | `<url>` | Открыть URL на вкладке Web |
| `clear` | — | Очистить вывод |
| `ps` / `list` | — | Список запущенных процессов |
| `blocks` / `ls` | — | Список загруженных блоков |
| `kill` | `<pid>` | Завершить процесс |
| `spawn` | `<name> [prio] [ram_mb]` | Запустить процесс (prio: 0-4) |
| `load` | `<name> [version]` | Загрузить блок |
| `unload` | `<id>` | Выгрузить блок |
| `status` / `info` | — | Статус системы |
| `logs` | — | Просмотр журнала безопасного режима |
| `restart` | — | Перезапустить оркестратор |
| `help` / `?` | — | Показать все доступные команды |
| `exit` | — | Выйти из оболочки безопасного режима |

### Справка F1

Справка F1 отображает все горячие клавиши и команды shell во всплывающем окне.

| Клавиша | Действие |
|---------|----------|
| `F1` или `?` | Открыть справку |
| `F1`, `Esc` или `?` | Закрыть справку |

## TUI ядра (`aios`)

### Запуск

```bash
cargo run --bin aios
# или из скомпилированного бинарника:
./target/release/aios.exe
```

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Tab` / `F1` | Следующая вкладка |
| `1`-`4` | Прямой выбор вкладки |
| `Alt`+`1`-`4` | Прямой выбор вкладки даже при активной строке URL браузера или строке AI-запроса |
| `g` | Открыть URL дашборда моста (`http://localhost:8080`) в браузере |
| `b` | Открыть URL в системном браузере (режим ввода URL) |
| `r` | Переопределить оборудование |
| `Space` | Пауза/возобновление журнала событий |
| `q` | Выход |

### Клавиша браузера (`b`)

Браузерный блок регистрируется при загрузке ядра — не нужны ни конфигурация, ни установленный браузер, ни сеть. Нажмите `b`, введите полный URL (например `https://example.com`), нажмите `Enter`: URL уходит в браузерный блок по IPC (команда `open_native` через `MessageRouter`) и открывается в системном браузере по умолчанию. Результат отображается в панели событий.

## GUI (`aios-gui`)

### Запуск

```bash
cargo run --bin aios-gui
```

### Компоновка

```
┌──────────┬───────────────────────────────────────────┐
│          │  AIOS v1.0.0 | Tier1 | WD: OK | RAM: ... │  ← Верхняя панель
│ Overview │───────────────────────────────────────────│
│ Processes│                                           │
│ Blocks   │          Центральная панель                │
│ Marketpl.│     (изменяется в зависимости от вкладки) │
│ Metrics  │                                           │
│ Deps     │                                           │
│          │───────────────────────────────────────────│
│ ──────── │  F1-F6 вкладки | AIOS Dashboard           │  ← Нижняя панель
│ Быстрые  │
│ действия │
└──────────┴───────────────────────────────────────────┘
  Боковая           Основная область
  панель
```

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `F1`-`F6` | Переключить вкладку |
| `j` | Переместить выделение вниз |
| `k` | Переместить выделение вверх |

### Мышь

- Клик по названиям вкладок в боковой панели для переключения
- Клик по строкам в таблицах для выделения
- Клик по кнопкам для действий (Убить, Приостановить, Загрузить и т.д.)
- Ввод в полях поиска (Маркетплейс)

### Вкладки

#### Обзор (F1)
- **Карточки статистики**: RAM (использовано/всего), Количество блоков, Количество процессов, Статус Watchdog
- **Панель системы**: Модель CPU, ядра, потоки, AVX2/AVX-512/SSE4.2, GPU, хранилище
- **Использование RAM**: прогресс-бар + спарклайн (последние 60 сэмплов)
- **Журнал активности**: прокручиваемый журнал с цветовой кодировкой

#### Процессы (F2)
- **Таблица**: PID, Имя, Приоритет (цветовой), Состояние (бейдж), RAM, CPU, Сбои
- **Действия**: Убить, Приостановить, Возобновить
- **Панель деталей**: информация о выбранном процессе

#### Блоки (F3)
- **Таблица**: ID, Имя, Версия, Состояние (бейдж), Размер, Зависимости
- **Действия**: Обновить, Загрузить блок (2-шаговый диалог), Выгрузить, Горячая замена
- **Диалог загрузки**: Шаг 1 — ввести имя блока, Шаг 2 — ввести версию, Enter/Отмена

#### Маркетплейс (F4)
- **Поле поиска**: фильтр по имени, описанию или тегам
- **Таблица**: Имя, Версия, Автор, Статус (бейдж), Загрузки
- **Действия**: Установить, Обновить, Удалить
- **Статус**: показывает результат операции

#### Метрики (F5)
- **RAM**: прогресс-бар + спарклайн
- **Распределение приоритетов**: столбчатая диаграмма (Background / Low / Normal / High / Critical)
- **Статистика блоков**: количество по состояниям с прогресс-барами
- **Информация о системе**: CPU, GPU, хранилище

#### Зависимости (F6)
- **Сводка**: количество блоков + количество связей
- **Цепочка загрузки**: визуальная цепочка (блок A → блок B → блок C)
- **Таблица**: Имя блока, Зависит от, Зависят от него

### Тема

Тёмная тема с настраиваемыми цветами в `aios-gui/src/theme.rs`:

| Цвет | Назначение |
|------|------------|
| `accent` (#00C8DC) | Заголовки, активные вкладки, выделение |
| `success` (#32C850) | Рабочие блоки, OK статус, положительные значения |
| `warning` (#F0B41E) | Приостановленные, High приоритет, предупреждения |
| `danger` (#E63C3C) | Crash, Critical, ошибки |
| `info` (#64A0FF) | Low приоритет, информационные |
| `muted` (#78788C) | Фон, затемнённый текст, Terminated |
| `surface` (#181820) | Основной фон |
| `surface_alt` (#22222E) | Фон карточек, чередующиеся строки |

## Web (`aios-studio`)

### Запуск

Веб-интерфейс автоматически раздаётся `aios-bridge` как статические файлы. Запустите:

```bash
cargo run --bin aios-tui   # или любой бинарник, запускающий aios-bridge
# Откройте http://localhost:9876 в браузере
```

SPA доступно по корневому URL. Порт моста настраивается параметром `addr` в `start_server()`.

### Дашборд (вкладка по умолчанию)

- **Карточки здоровья**: статус системы, состояние Watchdog, количество процессов, использование RAM
- **График RAM**: Canvas-график в реальном времени, 120 точек (12 секунд с интервалом 100ms)
- **Таблица процессов**: PID, Имя, Память, Время CPU, Статус с цветовой индикацией

### Smart Command Palette

- **Открытие**: `Ctrl+K` или `Cmd+K` (macOS)
- **Закрытие**: `Escape` или клик вне палитры
- **Использование**: Введите команду на естественном языке и нажмите Enter
- **Поддерживается**: действия с процессами (список, убить, запустить), блоками (загрузить, выгрузить), системные запросы (статус, память, CPU), сжатие памяти
- **Языки**: английский + русский (двуязычный парсер намерений)
- **Результат**: описание, JSON-результат, список использованных capability-токенов

### Security Center

- **Таблица блоков**: ID, Имя, Версия, Состояние, кнопка остановки
- **Сетка capability**: шесть токенов (CAP_PROCESS_KILL, CAP_PROCESS_SPAWN, CAP_BLOCK_LOAD, CAP_BLOCK_UNLOAD, CAP_SCHED_MODIFY, CAP_MEM_ALLOC) с описаниями
- **Быстрые действия**: Сжать память, Список блоков, Список процессов

### Статус подключения

- **Нижняя часть боковой панели**: цветовой индикатор
  - Зелёный = Connected
  - Жёлтый = Reconnecting (экспоненциальная задержка)
  - Красный = Disconnected / Error
- Автопереподключение WebSocket с задержкой 1с → 15с

### Требования

- Любой современный браузер (Chrome, Firefox, Safari, Edge)
- Не требует JavaScript-фреймворков — 0 npm-зависимостей
- Поддержка WebSocket (все современные браузеры)

## Архитектурные заметки

- **TUI** использует `ratatui` + `crossterm` — работает в любом терминале, доступен через SSH
- **GUI** использует `egui` + `eframe` — нативное окно, GPU-ускоренная отрисовка
- Оба читают из одной модели `DashboardState` / `AiosApp`
- Ни один интерфейс не выполняет аппаратные операции напрямую — они запрашивают операции через планировщик/менеджер блоков
- Все данные снимковые: `DashboardState::update_from_scheduler()` (TUI) или `AiosApp::new()` (GUI, начальный)

## Daemon (`aiosd`)

### Запуск

```bash
# По умолчанию (headless, для Docker)
aiosd

# С кастомными директориями
AIOS_DATA_DIR=/mnt/data AIOS_BLOCKS_DIR=/mnt/blocks aiosd

# С профилем
AIOS_MOCK_PROFILE=legacy aiosd
```

### Переменные окружения

| Переменная | По умолчанию | Описание |
|-----------|-------------|----------|
| `AIOS_DATA_DIR` | `/app/data` | Директория persistent БД |
| `AIOS_BLOCKS_DIR` | `/app/blocks` | Директория бинарников блоков |
| `AIOS_MOCK_PROFILE` | `modern` | Профиль железа: `modern`, `legacy`, `none` |
| `RUST_LOG` | `info` | Уровень лога: `error`, `warn`, `info`, `debug`, `trace` |

Daemon выполняет ту же инициализацию, что и `aios-tui`, но без терминального интерфейса:
1. Загружает встроенные блоки (hal, ipc_bus, scheduler)
2. Загружает блоки с диска из `AIOS_BLOCKS_DIR`
3. Открывает persistent БД в `AIOS_DATA_DIR/context.redb`
4. Запускает системные процессы (ai_orchestrator, io_handler, health_monitor)
5. Запускает поток heartbeat watchdog
6. Логирует heartbeat с кол-вом процессов, RAM, состоянием watchdog каждые 10 секунд
7. Сохраняет телеметрию в БД каждые 60 секунд

## Запуск всех интерфейсов

Все четыре интерфейса (Web, TUI, GUI, Daemon) могут работать одновременно. Web SPA подключается к `aios-bridge` через HTTP/WebSocket и является чисто удалённым клиентом. TUI и GUI — встраиваемые интерфейсы, создающие собственные экземпляры `Scheduler` и `BlockRegistry` локально.
